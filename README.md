## Sobre o Projeto
Página web desenvolvida como atividade de HTML e CSS. O objetivo é praticar a estruturação de conteúdo, a exibição de imagens locais organizadas em pastas e a estilização com CSS, incluindo o layout em colunas com Flexbox.

---

# Tecnologias Utilizadas
- HTML5
- CSS (inline, interno e externo)
- CSS Reset baseado no modelo de Eric Meyer
- Flexbox para organizar as três seções lado a lado
- Imagens locais organizadas em diretorio propio (/imagens)

---

# Conteúdo da Página
A página é dividida em três seções, cada uma com três itens ilustrados por imagem e uma descrição:

| Seção | Itens |
|---|---|
| Filmes e Séries | Como Treinar O Seu Dragão, Godzilla Minus One, Percy Jackson e os Olimpianos |
| Música e Podcasts | 99Vidas, Reloading, Eternity (Alex Warren) |
| Games e Tecnologia | Assassin's Creed, Dragon Ball Z: Budokai Tenkaichi 3, F1 25 |

# Como Executar o Projeto

1. Faça o download deste repositório para o seu computador.
2. Certifique-se de manter a pasta `imagens` com os arquivos correspondentes no mesmo diretório do arquivo `index.html`.
3. Dê dois cliques no arquivo `index.html` para abri-lo em qualquer navegador (Chrome, Firefox, Edge, etc.).
